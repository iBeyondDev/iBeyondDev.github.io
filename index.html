// tooling & workflow

Custom editor tools I built to speed up level design workflows — written in C# against the Unity Editor API.

EDITOR EXTENSION · C#

Asset Scattering Tool

Unity Editor · Custom tooling

Paints prefabs directly into the scene with randomized scale and rotation per instance — turning minutes of manual placement into seconds. Built for dressing environments with rocks, foliage, and props.

EDITOR EXTENSION · C#

Path Tool

Unity Editor · Custom tooling

An in-scene path editor with handles for adding, moving, and editing points directly in the viewport — for building AI patrol routes, moving platforms, and camera paths without leaving the scene view.
